Built for writers who want assistance, not authorship by proxy.

Coverage keeps AI changes visible and reviewable. You decide what enters the screenplay, what stays in the outline, and what gets rejected.

What it does

A writing room that fits on your screen.

01

Outline beside the draft

Build acts and beats with a visual board that appears when you need it—without abandoning the screenplay underneath.

ACT 1
ACT 2
ACT 3
02

Screenplay-aware editing

Write with automatic element formatting, scene navigation, pagination, and export.

03

Review every AI change

Accept or reject structured edits in place. Nothing silently rewrites your work.

04

Full-project context

The assistant can reason across the screenplay, outline, characters, and current selection.

05

Open architecture

A React client, Node API, FastAPI agent service, and PostgreSQL—all inspectable and adaptable.

The workflow

One story. Three modes.

ASK

Understand the draft

Explore character, continuity, pacing, and structure without changing the screenplay.

EDIT

Shape the pages

Generate precise, structured revisions and review each one before it becomes part of the script.

OUTLINE

Build the story

Develop acts and beats in conversation while the visual outline updates beside you.

Run it yourself

From clone to first page.

Coverage runs locally and keeps the complete stack visible. Bring your own API key for AI features, or use the screenplay editor on its own.

Read the full setup guide →
terminal
$ git clone git@github.com:alexminnaar/Coverage.git
$ cd Coverage
$ npm install
$ npm run dev
